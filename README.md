# ZEE5 Clone 🎬

A front-end clone of the **ZEE5** streaming platform built using **HTML** and **CSS**.  
This project is created for learning and practice purposes to improve UI design, layout structuring, and responsive web design skills.

> ⚠️ **Disclaimer:**  
> This project is **not** affiliated with, endorsed by, or connected to ZEE5 or Zee Entertainment Enterprises in any way.  
> All trademarks and logos belong to their respective owners. This clone is made purely for **educational** purposes.

---

## 🎯 Project Goals

- Practice building complex layouts with **HTML & CSS**
- Understand **Flexbox / Grid** layouts
- Recreate a modern OTT platform UI
- Explore responsive design for different screen sizes

---

## 🧩 Features Implemented

- ✅ ZEE5-style **navbar** with logo and menu items  
- ✅ **Hero section** with featured show/banner  
- ✅ **Content carousels/rows** for movies, shows, etc. (static)  
- ✅ **Hover effects** on cards/posters  
- ✅ **Footer** with links and basic info  
- ✅ **Responsive layout** for desktop / tablet / mobile (if you’ve added media queries)

> You can edit this list based on what you actually implemented.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
  - Flexbox
  - CSS Grid (if used)
  - Media Queries (if used)

_No JavaScript is used for functionality in this version (pure front-end UI clone)._
